# LangGraph

> Build stateful, multi-actor agents as graphs.

| | |
|---|---|
| Package | `langgraph` |
| First released | 2024 |
| Minimum Python | 3.7+ |
| Primary use case | Long-running, multi-step agents and human-in-the-loop workflows. |

LangGraph models agents as graphs: nodes are functions, edges define control flow, and a typed state object is passed between them. Built-in persistence (checkpointers), interrupts, and streaming.
