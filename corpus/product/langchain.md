# LangChain

> The framework for building LLM applications.

| | |
|---|---|
| Package | `langchain` |
| First released | 2022 |
| Minimum Python | 3.10+ |
| Primary use case | Composable LLM pipelines, RAG, and agents. |

LangChain provides chains, agents, retrievers, and integrations with 700+ providers. Use it to compose LLM calls with tools, memory, and structured outputs.
