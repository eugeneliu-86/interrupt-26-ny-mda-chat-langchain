# Deep Agents

> Long-horizon agents with planning, memory, and subagents.

| | |
|---|---|
| Package | `deepagents` |
| First released | 2024 |
| Minimum Python | 3.10+ |
| Primary use case | Research, coding, and other tasks that need planning and many tool calls. |

Deep Agents wraps create_agent with a TodoList planner, virtual filesystem, and SubAgentMiddleware for context isolation. Inspired by Claude Code's harness pattern.
